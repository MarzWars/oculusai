## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it to us confidentially. Do **not** open a public GitHub issue for security bugs.

### How to Report

Please send security reports via email to **[info@lexdigitals.co.za](mailto:info@lexdigitals.co.za)**. 

To help us address the issue quickly, please include:
- A description of the vulnerability and its potential impact.
- Detailed, step-by-step instructions to reproduce the issue (including any proof-of-concept code or scripts).
- The version(s) of the project affected.

### What to Expect

* **Acknowledgment:** You will receive an initial response acknowledging receipt of your report within 48 hours.
* **Status Updates:** We will keep you updated on our progress as we investigate and work on a fix.
* **Resolution:** If the vulnerability is confirmed, we will coordinate a release date for a patch and credit you for the discovery (unless you prefer to remain anonymous).
